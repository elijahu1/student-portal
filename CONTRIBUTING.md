# Contributing

This is a university project for CSC 442. If you'd like to suggest improvements or report bugs, feel free to open an issue or submit a pull request.

## How to Contribute

1. Fork the repository
2. Create a new branch: `git checkout -b feat/your-feature`
3. Make your changes
4. Commit: `git commit -m "feat: description of change"`
5. Push and open a pull request

## Guidelines

- Keep code clean and readable
- Use PDO prepared statements for all database queries
- Escape all output with `h()` (htmlspecialchars wrapper)
- Test locally before submitting
- One feature or fix per pull request
